# B题四问统一重构架构

> 版本：v0.2
> 状态：当前有效；Q1–Q4 已统一采用一阶航向惯性纯追踪和舰载 UAV 起飞
> 逻辑主线：
>
> \[
> \text{解析判定}
> \rightarrow
> \text{单弹候选}
> \rightarrow
> \text{多弹联合覆盖}
> \rightarrow
> \text{多机协同}
> \rightarrow
> \text{多威胁资源调度}.
> \]

## 1. 总体架构

四问不应各自建立一套模型。公共层只定义一次：

1. 连续动力学：舰船、惯性纯追踪导弹、舰载起飞无人机；
2. 混合事件：指令、投弹、起爆、衰减、失效、探测、命中；
3. 烟幕区域：\(C_j(t)\)；
4. 探测集合：\(\mathcal D_i\)；
5. 联合覆盖缺口：
   \[
   g_{\mathcal J}(t)=
   \max_{\boldsymbol x\in S(t)}
   \min_{j\in\mathcal J}
   (\|\boldsymbol x-\boldsymbol c_j(t)\|-R_j(t));
   \]
6. 可达性、路径连续性和安全距离；
7. 连续时间独立认证器。

各问只改变决策层和资源规模，不改变物理事实。

## 2. 公共计算流水线

```text
题面事实 + 已批准假设 + 场景参数
                 │
                 ▼
   生成9组惯性威胁轨迹与多分量探测集合
                 │
                 ▼
      解析上下界/不可能性证书
                 │
          可行才继续搜索
                 ▼
     生成时空投放候选与可达路径
                 │
                 ▼
       组合或连续优化产生候选解
                 │
                 ▼
  空间联合覆盖 + 连续时间 + 路径独立认证
                 │
                 ▼
      标准化任务包与可追溯结果
```

解析判定不仅用于Q1，也用于Q2–Q4剪枝。例如若某个威胁需要的连续覆盖时长超过三枚烟幕在给定可达条件下的理论上界，可以直接淘汰相应任务包。

## 3. 问题一：单弹解析判定与候选生成

### 3.1 问题卡片

| 项目 | 内容 |
|---|---|
| 输入 | 单威胁几何场景、9组惯性参数、题面公共参数、已批准假设 |
| 决策 | UAV起飞时刻 \(\tau_u\)、\(t^c,t^d,t^e,\boldsymbol p^d,\boldsymbol c_e\)、无人机路径 |
| 严格目标 | 全探测窗口100%完整覆盖 |
| 次级目标 | 覆盖时长、最大空档、覆盖裕度、航程、鲁棒裕度 |
| 核心约束 | 惯性导弹距离—视场事件、舰载起飞、起飞后28 m/s且无悬停、2 s响应、3.5 s惯性、相对运动舰船12000 m作战半径、集合包含 |
| 输出 | 单弹候选、分量级解析证书、三值认证状态、9组参数范围 |

### 3.2 求解顺序

1. 对 9 组 \((k,\omega_{\max})\) 分别积分导弹轨迹；
2. 由距离和视场事件提取
   \(\mathcal D=\bigcup_\ell[a_\ell,b_\ell]\)；
3. 运行最早烟幕形成证书；
4. 对每个探测分量使用
   \(T_{\rm cover}^{(1)}\le80/7.71\) 检查严格目标；
5. 若严格目标不可行，保存不可行证书；证书未否定时不得反向声称可行；
6. 将待覆盖时间中心 \(t_0\) 作为主变量，令候选起爆中心靠近 \(\boldsymbol s(t_0)\)；
7. 从起爆中心反演 98 m 投弹点圆；
8. 与从 \(\boldsymbol s(\tau_u)\) 出发的舰载 UAV 可达集、相对运动舰船作战半径求交；
9. 构造连续路径并复核末端航向；
10. 对剩余低维变量做网格/一维搜索或受约束局部优化；
11. 使用连续时间认证器输出最终状态，并汇总中值、范围和最不利组合；
12. 最后运行瞬时纯追踪消融。

### 3.3 主要数学收益

- 将原来的“任意二维投放点 + 时刻 + 航向”搜索降为“覆盖时间中心 + 少量航向/路径变量”；
- 先证明不可行，避免优化器为100%目标空转；
- 说明最大覆盖时长解通常不唯一；
- 输出可供Q2组合的标准候选。

### 3.4 推荐求解器

- 主：解析式 + 自适应时间网格 + 一维/低维有界搜索；
- 备：SLSQP或差分进化精修；
- 禁止：仅凭元启发式返回“全局最优”。

## 4. 问题二：单机多弹的联合时空覆盖

### 4.1 不能沿用的简化

原计划把每个烟幕转成“独立完整覆盖时间区间”，再做区间并集。这只能识别：

\[
\exists j:\ S(t)\subseteq C_j(t),
\]

不能识别题面允许的：

\[
S(t)\subseteq C_1(t)\cup C_2(t)\cup C_3(t).
\]

因此时间区间并集只能作为保守基线，不能作为主判据。

### 4.2 问题卡片

| 项目 | 内容 |
|---|---|
| 输入 | Q1单弹候选库、舰载单机、各惯性场景探测集合 |
| 决策 | 起飞时刻、最多3个候选、投弹顺序、时刻、路径连接 |
| 首要目标 | 消除全探测窗口裸露 |
| 次级目标 | 最小最大空档、最大联合裕度、最少弹药、最短航程 |
| 核心约束 | 同机路径连续、相邻投弹至少1 s、载弹量≤3、联合集合覆盖 |
| 输出 | 经过认证的 `MultiSmokePlan` |

### 4.3 两层求解

**候选层**

- 由Q1可行带生成多种空间—时间烟幕候选；
- 每个候选保存投弹事件、路径端状态、烟幕区域函数；
- 对明显时间不重叠或路径不兼容组合提前剪枝。

**组合层**

- 0-1选择候选；
- 对每个候选组合计算联合 \(g_{\mathcal J}(t)\)；
- 在离散时间单元上生成认证覆盖标签；
- 使用MILP/分支定界选择组合；
- 最后连续精修起爆时刻和中心。

### 4.4 独立覆盖与联合覆盖对照

论文至少报告：

1. 只允许某一烟幕独立完整覆盖；
2. 允许多烟幕联合覆盖；
3. 联合覆盖带来的新增连续时长；
4. 烟幕重叠造成的资源冗余；
5. 单弹延迟或半径缩水下的鲁棒性。

烟幕重叠不是天然“好”或“坏”：适量重叠提高鲁棒性，过度重叠浪费时空资源。

## 5. 问题三：三机三弹协同

### 5.1 问题卡片

| 项目 | 内容 |
|---|---|
| 输入 | 三架舰载 UAV、每机一枚约束、Q1候选生成器、联合覆盖验证器 |
| 决策 | 每机起飞时刻、路径、投弹点、投弹时刻、起爆中心和时序 |
| 目标1 | 严格防御/覆盖时长 |
| 目标2 | 最大最坏覆盖裕度 |
| 目标3 | 最大单机或单弹失效后的剩余覆盖 |
| 目标4 | 最小总航程 |
| 约束 | 起飞后动态安全距离、同时同点起飞不可行、每机≤1枚、可达性、联合覆盖 |

### 5.2 “覆盖范围最大化”的解释

舰船等效区域已经固定为 \(S(t)\)，不能把“烟幕总面积越大”直接当作防御收益。建议把题面的覆盖范围解释为：

- 探测窗口内被完整覆盖的时间范围；
- 联合覆盖对舰船区域的最小几何裕度；
- 对舰船位置误差可容忍的区域；
- 单点失效后仍被覆盖的范围。

这比简单最大化 \(\operatorname{area}(\bigcup_jC_j)\) 更符合防御目标。

### 5.3 优化方法顺序

1. 词典序求解：严格成功优先；
2. 在成功层中用 \(\varepsilon\)-约束扫描容错—航程权衡；
3. 小候选库使用枚举或MILP；
4. 只有连续非凸规模仍过大时才使用NSGA-II；
5. NSGA-II结果必须通过相同验证器，并与枚举/多起点局部优化比较。

### 5.4 单点失效指标

设三枚烟幕集合为 \(\mathcal J\)，定义：

\[
\eta_{\rm fail}
=\min_{j\in\mathcal J}
\operatorname{coverage}
(\mathcal J\setminus\{j\}).
\]

同时报告最坏最大空档，不能只报告平均覆盖率。

## 6. 问题四：威胁评分与资源调度分离

### 6.1 输入异质化

每枚导弹 \(i\) 的场景输入包括：

\[
\boldsymbol m_i(t_i^{\rm app}),\quad
v_{m,i},\quad
\text{来袭方向},\quad
\text{批次到达时刻},\quad
\text{损失等级}.
\]

标准场景可取320 m/s，但问题四允许“不同速度”覆盖该值，且必须标明是场景数据或假设。
正式制导模型固定为惯性纯追踪。为避免 \(9^n\) 组合爆炸，同一次 Q4 仿真的同型号导弹共享一组
\((k,\omega_{\max})\)，每个资源场景运行 9 个全局参数版本。

### 6.2 威胁评分

威胁评分只描述危险程度，可用可解释指标：

- 预计命中时间 \(T_{\rm hit,i}\)；
- 距进入探测窗口时间 \(T_{\rm entry,i}\)；
- 防御几何难度；
- 未防御损失等级；
- 可用任务包的最佳覆盖上界。

无数据时不使用熵权。权重若不可避免，来自明确任务优先级，并做排序稳定性分析。

### 6.3 任务包

Q1–Q3生成：

```text
P1: 1机1弹
P2: 1机2弹
P3: 1机3弹
P4: 3机各1弹
```

每个任务包不是一个名称，而是经过验证的数据对象，包括资源、时间窗、起终状态、覆盖证书、鲁棒性和航程。

### 6.4 滚动时域MILP

决策变量可表示“威胁—任务包—开始时间—无人机”的分配。目标按词典序：

1. 最大化高损失威胁的认证防御收益；
2. 最小化最大未覆盖风险；
3. 最小化弹药；
4. 最小化航程和任务切换。

约束：

- 5架无人机；
- 每机最多3枚；
- 时间和路径连续；
- 投弹间隔；
- 动态安全距离；
- 任务不重叠；
- 每个任务包的适用窗口；
- 可选冗余不能挤占更高优先级未防御威胁。

新批次出现、威胁状态变化或任务失败时滚动重算。

## 7. 鲁棒性贯穿四问

鲁棒性不应只放在最后做1000次蒙特卡罗。采用三层输出：

1. **中值参考解**：\(k=1\rm\,s^{-1}\)、
   \(\omega_{\max}=10^\circ/\rm s\)，明确标记为团队假设；
2. **惯性参数范围**：报告 9 组结果范围和最不利组合；
3. **有界鲁棒解**：位置、时间、半径、速度和风漂在给定误差盒内均满足；
4. **概率评估**：仅在分布有依据时报告机会约束或蒙特卡罗置信区间。

每个Q1候选和Q2/Q3任务包都带鲁棒裕度，Q4可以直接比较资源效率与可靠性。

## 9. 最小实现顺序

基准假设层已获团队批准，建议按下列顺序重写原Implementation Plan：

1. 题面/假设/场景配置校验和 144 个正式惯性场景；
2. 航向惯性导弹 ODE、事件积分和多分量探测集合；
3. 舰载 UAV 起飞、路径和移动参考约束；
4. Q1 分量级解析证书测试；
5. 单烟幕解析判定和可达域；
6. 多烟幕联合覆盖认证器；
7. Q1候选生成；
8. Q2组合优化；
9. Q3协同与容错；
10. Q4任务包和 9 组全局参数滚动调度；
11. 鲁棒验证、瞬时纯追踪消融与论文绑定。

联合覆盖认证器应早于Q2优化器完成，否则后续组合结果没有可信判据。
