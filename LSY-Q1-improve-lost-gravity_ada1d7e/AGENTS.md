# 数学建模项目说明

本项目使用项目级 `mathmodel-skill`：

1. 开始数学建模相关工作前，读取 `.agents/skills/mathmodel-skill/SKILL.md`。
2. 按需读取该技能目录下的 `references/`、`competitions/`、`templates/`、`scripts/` 和 `config/`。
3. 用户产物写入项目根目录的 `state/`、`results/`、`figures/` 和 `paper_workspace/`。
4. 默认使用中文；涉及关键选择时采用编号问答。
5. 不一次性加载全部参考资料，只加载当前阶段需要的文件。
