# Q3 三机协同模型

Q3 主解释固定为三架无人机、每架恰好投放一枚。每架 UAV 从舰船起飞，使用独立的事件参数（指令、实际投弹、起爆时刻和固定烟幕中心），再通过联合覆盖 verifier 检查舰船 80 m 探测圆盘。

"至多一枚"只作为放松对照接口保留，本轮主结果不把少于三枚的方案混入正式解释。没有来源的转弯半径、风场或额外载荷效率不被添加到基准。

## 目标与约束编号

三架 UAV 的决策向量为 \(\mathbf{x}_3=(t_k^c,t_k^d,t_k^e,c_k,p_k^d)_{k=1}^3\)，每架恰好一枚。
成功优先词典序目标为 \(\mathcal{J}_3=(I_{\rm coop},T_{\rm cov}^{\rm lower},-T_{\rm gap}^{\max},M_{\rm failure},-E_{\rm proxy})\)。
约束编号为：

1. `(Q3-C1)` \(t_k^d=t_k^c+2,\;t_k^e=t_k^d+3.5,\;t_k^c\ge0\)；
2. `(Q3-C2)` 每个 UAV 恰好一枚，三条路径连续、速度为 28 m/s，且均在 12 km 作战半径内；
3. `(Q3-C3)` 两两 UAV 路径通过 pairwise separation 证书；正式基准只使用来源支持的 0 m 安全下界；
4. `(Q3-C4)` 三个烟幕并集覆盖完整 80 m 舰船圆盘；
5. `(Q3-C5)` 以 ε 约束记录最大裸露和最小路径间距，认证状态仍由独立 verifier 决定。
