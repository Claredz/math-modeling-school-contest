# Stage 6 鲁棒性与边界综合

失锁—重捕获模型只在四个代表性 Q1 正式 `candidate_id` 上作为 `experimental_counterfactual` 审查，登记参数 \((\tau_T,\tau_L,T_R)\)，保持 command/drop/burst/center、释放位置、UAV path 和 smoke plan 不变，不复制同学实验分支的正式结果，也不改写正式假设表。固定中心、题面半径和连续时间认证仍是正式基线；有界漂移与半径误差只作为后续鲁棒扩展接口。

Q2/Q3 的认证覆盖、认证裸露和未决单元分别进入上下界；最大连续裸露保留认证下界与可能上界。Q4 的未安排或未认证任务保留 `unresolved`。这使鲁棒性结论保持证据等级边界，而不是把离散采样或局部优化当作证明。
