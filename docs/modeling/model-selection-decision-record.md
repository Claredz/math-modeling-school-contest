## 四问目标层级

1. Q1：严格全窗口覆盖 → 最大认证覆盖总时长 → 最小最大连续裸露时长 →
   最大最小覆盖裕度 → 最少航程或资源。严格不可行后继续优化后续层级，资源不先于
   覆盖质量。
2. Q2：严格全窗口覆盖 → 最大最长无空档连续覆盖时长 → 最大认证有效遮蔽总时长 →
   最小最大连续裸露 → 最小总裸露 → 最大联合覆盖裕度 → 最少弹药 → 最短航程。
   前两种时长口径均保留为 Stage 4 候选目标定义。
3. Q3：严格协同防御成功 → 最大认证覆盖能力 → 最小最大裸露或失效风险 →
   最大单点失效容错 → 最小能耗与冲突风险。采用词典序和 ε-约束；NSGA-II
   仅作 Pareto 前沿覆盖基准。
4. Q4：最大化认证防御的高损失威胁 → 最大化认证防御威胁总价值 →
   最小未防御损失 → 最小资源消耗 → 最小重调度波动。在线因果策略、离线全知
   hindsight 上界、任务包内近似和原始连续联合优化必须分开报告。

## 推荐组合

| 模块 | 推荐 | 保证边界 | 备用/反事实 |
|---|---|---|---|
| 导弹 | 最小参数纯追踪基准 | 只在给定解释下仿真 | 一阶惯性、PN 参数扫描 |
| 遮蔽 | 舰船圆盘被活动烟幕并集连续覆盖 | verifier 认证给定候选 | 单烟幕特例、视线阻断、轮廓点近似 |
| 烟幕 | 题面分段半径、固定中心基准 | 不引入无来源风场 | 有界漂移鲁棒层 |
| UAV | 事件参数化分段直线基准 | 不证明真实转弯可飞 | 有转弯半径后的 Dubins |
| Q1 | 解析降维 + 多路线探索 + 局部精修 + verifier | 只批准框架，不冻结主优化器 | Multi-start、Sobol、SHGO、DE、PSO |
| Q2 | 时空 SIP + constraint generation + separation + verifier | 第一优先研究路线；oracle 未认证时 unresolved | 候选组合、MINLP、LBBD、确定性全局方法 |
| Q3 | 成功优先词典序 + ε-约束 | NSGA-II 仅作覆盖基准 | 分层分配、联合 MINLP |
| Q4 | 认证任务包 + 因果在线决策 + 滚动研究框架 | 当前 rolling 是弱基线；主算法待 benchmark | 因果贪心、离线上界、直接联合反事实 |

Q1 的 synthetic toy 中，SHGO、Sobol 和 Multi-start 原生成功；DE 达迭代上限后
依赖局部 polish，PSO 无原生收敛证书。因此 DE、Sobol、SHGO 和 Multi-start
进入正式主路线 benchmark，PSO 仅保留为启发式对照、不作为默认主方法；单个二维
人工函数不支持预先冻结 DE。

Q2 的 SIP 是问题结构判断，不是算法已经完成。当前联合 toy 的候选组合路线局部
精修失败，constraint-generation 路线达到迭代上限，两者均为 `unresolved`，
且全局界差仍大。正式主问题可能非凸，separation 子问题也可能需要全局优化；
只有正式时空 oracle、停止准则和误差界通过后，才能确定正式主算法。

Q4 的 zero-forecast、whole-package-commitment rolling 在 synthetic toy 中为
13，低于因果贪心 18；离线全知上界为 19。弱基线整包不可撤销、无预测、无终端
价值/惩罚、无资源保留和机会成本，也不能替换未执行任务。正式阶段至少比较两个
改进版本，并用 regret 与 hindsight gap 评价；贪心结果必须如实保留。
