# Q4 因果滚动调度模型

Q4 消费经过 Q1–Q3 verifier 认证的任务包，而不是直接消费局部优化器状态。每个威胁任务有揭示时刻、认证覆盖下界、价值和资源成本；滚动决策只使用当前时刻已经揭示的任务。

本轮比较 abundant、critical、shortage 三种资源工况。调度结果不宣称原问题全局最优，任务包集合是经验证候选的内近似。

## 目标与约束编号

对认证任务包 \(i\) 定义二元分配变量 \(x_i\)、揭示时刻 \(r_i\)、价值 \(v_i\) 和资源成本 \(a_i\)。在线目标为
\(\mathcal{J}_4=(\text{认证防御任务数},\sum_i v_ix_i,-\text{未防御损失},-\sum_i a_ix_i,-\text{重调度波动})\)。
约束为：

1. `(Q4-C1)` \(\sum_i a_ix_i\le A\)；
2. `(Q4-C2)` 在线决策时刻 \(t_i\ge r_i\)，只允许读取已揭示任务；
3. `(Q4-C3)` 选中任务必须来自 Q1–Q3 的认证任务包；未认证包在 `feasible` 过滤前即被排除，既不消耗容量，也不进入 `decisions`、`total_value` 或 `certified_value`；
4. `(Q4-C4)` 资源不足或 verifier 未闭合的任务保留 `unresolved`；
5. `(Q4-C5)` hindsight 枚举只作为离线上界，不能作为在线策略。
