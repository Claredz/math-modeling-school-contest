# 模型与算法证据映射

## 1. 证据等级

| 等级 | 含义 | 可支持的声明 |
|---|---|---|
| E1 | 题面直接事实/直接推导 | 本题硬输入或数学转写 |
| E2 | 同行评议方法对本结构直接适用 | 主候选，但仍需 toy 验证 |
| E3 | 邻近领域机制或算法 | 备选/反事实/敏感性 |
| E4 | 启发式、近期单例或参数不匹配 | 基准或污染样本，不支撑正式参数 |

文献等级不等于论文质量评分；它只表示对本题当前声明的迁移距离。

## 3. 各问算法映射

### Q1

| 候选 | 证据 | 保证边界 | Stage 3 判定任务 |
|---|---|---|---|
| 解析降维 + multi-start SLSQP | 题面几何；局部 NLP 常规方法 | 解析部分严格，局部搜索不全局 | 与人工对称例、解析上界对照 |
| DE + SLSQP | N01 | 启发式全局探索 + 局部结果 | 同预算、固定种子、独立 verifier |
| PSO + SQP | 只作通用群智能基准；污染论文不得供参数 | 无全局保证 | 比较稳定性和调用预算 |
| Sobol + trust-constr | N03 仅支撑采样/敏感思想 | 低差异覆盖不等于证明 | 比较覆盖率、局部精修与可行率 |
| 低维确定性全局方法 | P03/P06 的全局思想 | 仅在低维、可界定问题下 | toy 中给上下界或最优性 gap |

推荐前提：先做 Q1 审计，确认旧实现是否真正调用连续优化器。任何算法输出都需
单独连续时间验证。

### Q2

| 候选 | 证据 | 保证边界 | Stage 3 判定任务 |
|---|---|---|---|
| 候选组合 + 连续精修 | 工程基线 | 候选集最优，不是原空间最优 | toy 与联合连续基准比较遗漏 |
| SIP + constraint generation | P01、P02、P04、P09、P10 | 分离/主问题精度决定结论 | 人工例证明粗网格漏点且 oracle 找回 |
| LBBD | C02 | 需自然主从结构和有效割 | 检查割强度与子问题认证 |
| MINLP + separation oracle | P03–P06 | 全局保证成本高，局部 MINLP 无证书 | 小实例上下界/运行时间 |
| 元启发式 + 独立认证 | N01 | 只产候选 | 可行率、种子稳定性、unresolved |

当前证据优先级：`SIP + constraint generation + independent verifier`。这是
Stage 3 主候选，不是已经冻结的正式算法。

### Q3

| 候选 | 证据 | 保证边界 | Stage 3 判定任务 |
|---|---|---|---|
| 分层分配 + 连续优化 | S09、C01 | 分层可能损失联合最优 | 与小规模联合枚举比较 |
| 词典序 + ε-约束 | 题面 P7/P18 的优先结构 | 每个子问题求解精度决定前沿 | 人工可枚举 Pareto 例 |
| NSGA-II | C04 | Pareto 近似，无全局证书 | 前沿覆盖率与多种子稳定性 |
| 多机事件 MINLP | C01 | 规模和非凸性高 | 仅小实例比较可行率/时间 |

当前证据优先级：词典序成功层 + ε-约束；NSGA-II 作为基准。

### Q4

| 候选 | 证据 | 保证边界 | Stage 3 判定任务 |
|---|---|---|---|
| 认证任务包 MILP | C01 | 只在给定包集合内精确 | 小实例与直接枚举对照 |

| LBBD | C02 | 需任务包主问题/连续子问题强分解 | toy 中比较节点数和割 |
| 两阶段鲁棒/CCG | C03 | 需明确不确定集和两阶段语义 | 无数据时只做有界案例 |

当前证据优先级：认证任务包 + 滚动 MILP；LBBD/CCG 是条件升级候选。任务包方法
不得排除跨威胁共享烟幕和直接联合优化的反事实基准。

## 4. 最优性措辞映射

| 证据状态 | 允许表述 |
|---|---|
| 闭式推导且前提逐条满足 | 严格解析上界/不可行性结论 |
| 连续 verifier 给出有界余量 | 在给定模型和容差下认证可行/不可行 |
| 分支定界有上下界 | 当前 gap 为…；在该 gap 下最优 |
| 有限候选枚举 | 有限候选库最优 |
| NLP/序列凸化收敛 | 局部解或当前最好已知方案 |
| DE/PSO/NSGA-II | 启发式候选；多种子数值稳定/不稳定 |
| 区间尚未细分 | 容差下未决；计入风险上下界 |

## 5. Stage 3 前的明确否决

1. 否决把其他竞赛烟幕论文的 10 m、20 s、下沉速度写入本题。
2. 否决把 DE、PSO、NSGA-II 的算法名称当作全局保证。
3. 否决用 Q1 单弹可行候选定义 Q2/Q3 的联合可行域。
4. 否决在缺少转弯参数时直接把高阶 UAV 最优控制冻结为主模型。
5. 否决无不确定集时直接采用 CCG/机会约束。
6. 否决把 80 m 等效被探测半径当作毁伤半径。

以上否决在 Gate B 前有效；若新证据改变结论，必须写入决策记录并重新 red-team。
