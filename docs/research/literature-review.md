# B 题系统文献综述

## 1. 检索范围与核验规则

检索日期为 2026-07-30 至 2026-07-31。检索方向覆盖：

1. 烟幕/红外遮蔽机理、有效遮蔽面积和 UAV 烟幕协同；
2. 连续集合覆盖、圆盘并集、SIP、交换法和区间认证；
3. 导弹比例导引与视场几何；
4. 直接配点、多重打靶、序列凸化和多智能体混合优化；
5. DE、NSGA-II 和全局敏感性等算法/验证基准。

元数据优先通过 Crossref DOI API 复核；Crossref 没有当年在线优先记录的 S09，
改用期刊官方文章页复核。主流程对 31 个 DOI 做了二次批量查询，29 个当次返回
完整元数据；P05、P09 当次遇到临时 SSL 错误，但独立 agent 的 Crossref 重试已经
成功，故保留并明确标记。所有记录均给出 DOI 或期刊官方稳定页面。

纳入标准：

- 原始论文、正式期刊或会议论文；
- 能支撑一个明确的物理候选、算法候选或验证边界；
- 不把论文实例参数误当作本题参数；
- 能指出全局保证的适用条件或明确没有保证。

排除/降权标准：

- 只有聚合站、无法核验元数据；
- 与本题只共享“UAV/烟雾”关键词而没有模型关系；
- 新近竞赛衍生论文与本题题面高度相似、存在串题风险；
- 把启发式结果写成无条件全局最优。

## 3. 烟幕与遮蔽：能支持什么

S01–S06 共同说明，真实红外烟幕研究通常围绕传感器、透过率、有效遮蔽面积、
动态扩散和实验条件展开。因此，题面的“整个 80 m 等效区域被覆盖”应理解为本校赛
给定的几何代理，不宜声称等同于真实红外完全失效。

对本题最有价值的迁移是：

- 保持“候选生成器”和“独立遮蔽评估器”分离；
- 把透过率/浓度场作为高级扩展，而不是偷偷改写题面判据；
- 对风漂、半径误差和环境条件做鲁棒性分层；
- Q3/Q4 可比较分层协同，但每个任务包仍需统一验证器复核。

不能迁移的是任何论文中的烟幕半径、寿命、风速、沉降或三维扩散参数。本题基准
只能使用 P6 的 120 m、18 s 保持和随后 5 s 线性衰减。S07 的 puff 模型仅支持
“风漂是合理扩展”，不提供本题风场。

## 4. 连续集合覆盖与 SIP：Q2 的结构证据

P01 直接把连续集合覆盖表述为半无限优化；P02、P09 给出交换法/约束生成的经典
结构；P03–P06 说明在更强条件和更高计算成本下，可以建立可行性与全局界；P07、
P08 支持用 Apollonius/幂图寻找异半径圆盘几何中的候选最坏点；P10 支持网格加密
必须附带收敛论证。

由此得到的 Q2 主研究方向是：

\[
\text{有限主问题}
\rightarrow
\text{时空 separation oracle}
\rightarrow
\text{加入最坏违约见证}
\rightarrow
\text{连续精修/区间认证}.
\]

这并不自动产生全局最优。只有在全局主问题、全局分离子问题、正则条件和误差界都
满足时，才能写全局保证。竞赛实现更可能得到“在给定容差下认证可行/不可行，部分
区间未决”的结论。

## 5. 制导与 UAV 轨迹：复杂度必须由参数和收益证明

G02 支持 PN 作为结构不同的制导候选，但导航比、过载和光轴模型仍缺参数。它不能
证明 PN 就是题面“匀速追踪”的唯一解释。

G05–G08 分别支持直接配点、多重打靶和序列凸化。它们适合有明确动力学、转弯率和
边界条件的轨迹问题；本题只定性说 UAV 受机动性能约束，却不给数值。因此：

- 分段直线事件参数化是最小参数候选；
- Dubins/有限转弯候选必须扫描或获得转弯半径；
- 配点/多重打靶只有在 toy demo 显示明显必要性时才值得进入主候选；
- 任何 NLP/序列凸化结果默认是局部或条件收敛结果。

## 6. 混合优化与多目标：不因“高级”而自动入选

C01 支持任务分配与轨迹规划的分层结构。C02 的 LBBD 只有在离散主问题和可独立
验证的连续子问题能产生有效割时才合适；不能仅因 Q2/Q4 同时有离散和连续变量就
自动采用。C03 的 CCG 需要明确的两阶段不确定集。C04 的 NSGA-II 能近似 Pareto
前沿，但没有全局证书；Q3 的题面优先级很强，词典序加 ε-约束通常更可解释。

N01 支持 DE 作为全局探索启发式，不支持把其输出称作全局最优。N03 支持 Sobol
敏感性，但只有输入分布有依据时才具概率解释；否则先做有界扫描。

## 7. 串题污染隔离

`10.1109/ISCAIT69154.2026.11477504` 的 IEEE 官方摘要和正文片段显示，它研究
另一套三维 UAV 烟幕场景，并包含 10 m 有效半径、20 s 有效期和烟团下沉等设定。
这些与本题 P6 的 120 m、18+5 s 和二维水平面明显冲突。

该文只作为“PSO+SQP 确实有人用于类似部署”的污染样本，不计入核心文献，不进入
矩阵，也不为任何题面参数或正式模型背书。

## 8. 对 Stage 3 的约束性结论

1. 遮蔽主候选应保留题面圆盘完全覆盖，同时用视线/轮廓模型作反事实，不反过来
   覆盖题面定义。
2. 烟幕固定中心是最小参数候选；风漂和有界漂移只进入敏感性/鲁棒候选。
3. Q2 优先测试 SIP 约束生成；候选库只能 warm start，不能定义原始空间。
4. Q3 优先比较词典序/ε-约束与 NSGA-II 的可解释性、覆盖率和稳定性。
5. Q4 先测试任务包/滚动 MILP；LBBD/CCG 只有在 toy demo 出现强分解结构时升级。
6. DE、PSO、Sobol+局部法必须使用同预算、固定种子和独立验证器比较。
7. 文献提供的是候选和保证边界，不替代本题模型选型或 toy demo。
