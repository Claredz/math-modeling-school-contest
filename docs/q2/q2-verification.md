# Q2 联合覆盖验证

联合 verifier 对每个检测时间组件执行连续时间细分。在每个时间单元使用舰船速度界扩大目标圆盘、使用烟幕衰减速度收缩烟幕圆盘，再调用空间覆盖证书。闭合的单元才计入覆盖下界；达到时间容差仍无法闭合的单元保留为 `unresolved`。

输出同时给出：

- `coverage_lower_s` 与 `coverage_upper_s`；
- 总裸露时间的上下界；
- 最大连续裸露；
- 联合增益（相对单烟幕覆盖的增量）；
- 最坏时间见证和未决时间单元。

若路径超出 12 km 作战半径，直接返回 `certified_infeasible`。因此 Q2 结果中的 `certified_feasible` 只表示当前 verifier 已关闭的时间—空间包络，不表示全局最优；`unresolved` 不被隐藏或提升为可行。

本轮输出为四个代表性场景的当前最好已知多弹方案，并与 Q1 单弹覆盖时长作差，供论文结果表使用。
