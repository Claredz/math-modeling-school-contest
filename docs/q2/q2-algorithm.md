# Q2 候选生成与精修

流程固定为：

1. 从 Q1 已验证方案读取 warm start 起爆时刻；
2. 将检测区间的起止点、中点和 warm start 合并为事件锚点；
3. 枚举 1–3 枚弹的有序起爆时刻组合，生成连续分段直线路径；
4. 对候选执行 SLSQP 连续变量精修，显式保留 1 s 投弹间隔约束；
5. 每个候选交给独立联合覆盖 verifier；所有 1 枚弹候选先用同一场景、同一 verifier 计算最佳单烟幕覆盖下界，再把 `joint_gain_s` 定义为联合覆盖下界减该基线。排序使用认证状态、覆盖下界、最大连续裸露和该增益。

候选预算、随机种子和 verifier 口径在脚本中固定。搜索范围是 4 个代表性 Q1 场景，属于截止前可提交版本；没有实现完整 LBBD、通用 MINLP 或全矩阵 SIP 全局求解。

原生 solver 状态与 verifier 认证状态分开保存。局部优化器成功不等同于认证可行；结果同时保存覆盖/裸露区间、上下界、基线 candidate ID 和未决区间。
