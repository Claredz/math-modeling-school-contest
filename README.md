# 数模校赛

数学建模校赛项目工作区，已配置项目级 `mathmodel-skill` v6.0。

## 使用方法

在本目录中启动 Codex，然后直接说：

> 使用 `$mathmodel-skill` 开始建模

工作流支持 CUMCM 国赛、MCM/ICM 美赛和电工杯，包含选题、建模、求解、稳健性分析、论文写作与终稿审核。

## 目录结构

- `.agents/skills/mathmodel-skill/`：项目级数学建模技能
- `state/`：工作流状态
- `results/`：模型结果
- `figures/`：论文图表
- `paper_workspace/`：论文工作区
